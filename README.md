# Atom Information Measurement System (AIMS)

**AIMS** - приложение для контроля содержания в пробах и стандартах за отчетный период, измеренных с использованием ПО [Атом](https://www.vmk.ru/product/programmnoe_obespechenie/atom.html).

## Техническая документация

### **Настройки**
Рабочая директория задается **инженером** в конфигурационном файле `<ATOM_PATH>\AIMS\config.json`, или в приложении путем выбора директории `File/Open` (`Ctrl+O`).

**Конфигурационный файл**
Общие настройки приложения осуществляются посредством конфигурационного файла `<ATOM_PATH>\AIMS\config.json`, расположенного в рабочей директории приложения. Спецификация настроек:
- `version: str` - версия конфигурационного файла;
- `directory: str` - директория, изменения в которой отслеживается приложением. Все найденные в директории (включая внутренние папки) `*.xml` файлы анализируются приложением;
- `tracked_mode: "convergence-by-probes-control" | "convergence-by-parallels-control" = "convergence-by-probes-control"` - режим работы приложения (по умолчанию вычисляется сходимость по пробам);
- `tracked_period: "today" | "day" | "week" | "month" | "year" | "all" = "today"` - период отслеживания изменений;
- `tracked_analisys_name: str = ""` - отслеживаемый анализ (по умолчанию отслеживаются все анализы);
- `tracked_probe_name: str = ""` - отслеживаемая проба (по умолчанию отслеживаются все пробы);
- `tracked_queue_length: int = 5` - размер очереди отслеживания;
- `filtrated_by_sheet: str | null = null` - фильтрация по имени листа;
- `filtrated_by_label: "enginear" | "laborant" | "report" | "none" | null = null` - фильтрация по ключу столбца;
- `sep: str | null = "*"` - символ разделителя имени пробы по которому происходит маскирование информации пользователя.

**Настройки графического интерфейса**
Настройки графического интерфейса приложения осуществляются посредством файла `<ATOM_PATH>\AIMS\settings.ini`, расположенного в рабочей директории приложения. Спецификация настроек:
- `mainWindow` - настройки главного окна программы;
	- `visible: true | false = true` - показывать окно;
	- `menubar: true | false = false` - показывать строку меню;
	- `queue-widget: true | false = true` - показывать очередь измерений;
- `table` - настройки отображения таблицы:
	- `n_rows` - количество строк (`N_ROWS_MAX = 10`);
	- `n_columns` - **минимальное** количество столбцов. В случае, если все столбцы не помещаются в отведенное количество строк, то количество столбцов будет увеличено;
	- `filter-level` - фильтрация столбцов:
		- `NOTSET` - отображать все столбцы;
		- `NORMAL` - отображать только столбцы со счетными значениями;
		- `WARRING` - отображать только столбцы с отклонением выше порога `WARRING`;
		- `DANGER` - отображать только столбцы с отклонением выше порога `DANGER`;
	- `sorter-kind` - сортировка столбцов:
		- `NONE` - порядок определен `.xml` файлом;
		- `FILTER_LEVEL` - сортировка по уровню фильтрации;
- `style` - настройки отображания:
	- `font-size: int = 14` - размер шрифта (значение в диапазоне `[8, 24]`);
	- `font-weigh: 200 | 400 | 600 = 400` - насыщенность шрифта;
	- `header-height: int = 20` - высота заголовка столбца (значение в диапазоне `[8, 24]`);
	- `horizontal-header-width: int = 80` - ширина заголовка столбца (значение в диапазоне `[50, 500]`);
	- `vertical-header-width: int = 120` - ширина заголовка строки (значение в диапазоне `[50, 500]`);
- `geometry` - положение и размер окна:
	- `mainWindow` - основного окна приложения;
	- `reportIssueWindow` - окна Reprot Issue;
	- `baseKeyboardShortcutsWindow` - окна Keyboard Shortcuts;

#### Shortcuts
Главное окно:
- `Ctrl+O` - открыть диалог для выбора отслеживаемой директории;
- `Ctrl+Q` - закрыть приложение;
- `Ctrl+Shift+I` - показать/скрыть окно для отрпавки ошибки;

#### Handlers
Главное окно:
- `dblclick` по заголовку строки таблицы - открытие проводника с директорией, содержащий `.xml` файл;
