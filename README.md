# Atom Information Measurement System (AIMS)

**AIMS** - приложение для контроля содержания в пробах и стандартах за отчетный период, измеренных с использованием ПО [Атом](https://www.vmk.ru/product/programmnoe_obespechenie/atom.html).

## Installation
### Установка
Для работы приложения не требуется установка. Перед запуском приложения создайте папку `<ATOM_PATH>\AIMS\` внутри директории с ПО Атом `<ATOM_PATH>\` и скопируйте туда приложение.

## Использование
Для работы приложения требуется его запустить и выбрать директорию для работы (`Ctrl+O`). После первого запуска приложения автоматически (если требуется) создаются конфигурационные файлы для настройки приложения и его интерфейса.

Перед работой с приложением ознакомьтесь с документаций, расположенной в файле `docs.md`.
